# Clyde Dialogue Language

Clyde is a language for writing game dialogues. It supports branching, translations and interfacing with your game through variables and events.

The [language definition](https://thisisvini.com/clyde/en/language) should be used to implement interpreters and parsers. Proposals can be sent via issues.

This repository holds the docs and changelog for the language and related tools. Check the [documentation](https://thisisvini.com/clyde) for more details.
