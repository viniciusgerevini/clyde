# The Clyde Dialogue Language

```clyde

JOHNNY:
    It's too late, they start shooting in a week

VITO CORLEONE:
    I'm gonna make him an offer he can't refuse.
    Now you just go outside and enjoy yourself, and ah,
    forget about all this nonsense. I want you to leave
        it all to me.

JOHNNY:
    All right #exiting
 
```

The next sections cover Clyde language's features. All examples are valid dialogues that can be executed inline or in any valid interpreter.

You can find this language reference as a single [Markdown](https://thisisvini.com/clyde/en/clyde_language.md) or [HTML](https://thisisvini.com/clyde/en/clyde_language.html) file.
