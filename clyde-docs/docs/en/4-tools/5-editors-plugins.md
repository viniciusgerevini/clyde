# Plugins for other Editors

## VS Code plugin

[Clyde for VS Code](https://marketplace.visualstudio.com/items?itemName=viniciusgerevini.clyde-dialogue-language-vscode) adds support to Clyde files and enables the language server without requiring installing it externally. This includes all LSP features like syntax highlighting, auto completion, and jumps to definitions.

## Neovim / Vim

The [clyde.vim](https://github.com/viniciusgerevini/clyde.vim) plugin enables the clyde filetype recognition and comment symbol configuration. You still need to install the [language server](./1-language-server.md) and configure it separately.
